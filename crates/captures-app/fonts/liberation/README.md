# Liberation Fonts 2.1.5

Twelve **unmodified static TTFs** (Sans, Serif and Mono, each in regular, bold,
italic and bold-italic) for the experimental native editor. Licensed under
SIL OFL 1.1; the complete upstream copyright and license are in `LICENSE`. Keep
that notice with the app and font-bearing drafts. Screenshot pixels are not fonts.

Total font payload: 4,359,164 bytes (+2,709,184 from the former Sans-only set).
These are deterministic offline fonts,
not Tauri system-font equivalence or universal Unicode coverage. Missing glyphs
remain errors. No automatic OS-font discovery or network fallback is performed.
Saved drafts pin their family map and exact font files; opening a Sans-only draft
does not add Serif/Mono implicitly. Font migration is not implemented.
Do not alter/subset these files under their reserved names. New versions require
new immutable draft asset IDs and a provenance/license review.
