# OpenH264 notice

Captures compiles Cisco's OpenH264 source into Windows and Linux builds to
encode local H.264/MP4 recordings and edited exports. The source is supplied by
the BSD-2-Clause `openh264-sys2` Rust crate. Captures does not download Cisco's
prebuilt OpenH264 binaries at runtime.

See `LICENSE` in this directory for Cisco's license terms.
